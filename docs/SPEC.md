# Spec of keytech

## Goal
Play modern fighting games offline versus with tow virtual xbox360 gamepad using only one keyboard

## Must have(version 1)
1. two virtual XBox 360 gamepad
2. Customizable keymapping 
3. Saves the button config
4. UI that shows two gamepad and identifies keyboard mapping within it.
5. Toggle option to use as keyboard or gamepad using F9
6. Duplicate key alert

## Will not have(version 1)
1. RS and LS input
2. DirectInput Controllers
3. No macros

## Constraints
1. Windows only
2. No support for Linux/Mac

## Success Test
1. King of Fighters XV
2. Street fighter V
3. King of Fighters XIII

1. in-game overlay of both controller
